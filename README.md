# 頂級化妝品專案（premium-cosmetics）

版本：v1.0｜建立日：2026-10-25｜狀態：**規格完成，未送出、未簽約、未付費**

## 一、這個專案是什麼

Rokaizumi 合同會社（品牌：ROKAIZUMI ATELIER／露海澄研）的**頂級保養品產品線**，
由台灣安成生化科技有限公司代工，並接進主計畫的 **STO＋／RWA** 制度。

- 14 支 SKU，六大系列（澄／潤／曜／齡／御／沁）
- 分三批開發，首批 4 支（P0）
- 每支都有：功能定位、劑型、容量、成分功能類別、建議起始比例、法規上限、宣稱限制
- 每批商品可產出 RWA 批次憑證，接 STO＋ 多狀態模型

單位：TWD／支。匯率 USD 1 = TWD 32.0。

**三個結論**：
1. 12 支的包材成本高於料體成本 → 議價重點在瓶器與印刷，不在原料。
2. 多數 SKU 零售倍率超過 20 倍（精品常見 6–12 倍）→ 定價需下修或補足品牌力。
3. 原料漲 30% 對總成本影響僅 2–15% → 成本槓桿在包材與批量。

完整分析見 `docs\06_成本分析.md`。

單一 HTML 檔，資料全部內嵌，**不需要網路、不需要伺服器**。

- 直接雙擊 `web\index.html` 用瀏覽器開即可

**要一個免費公開網址**（給代工廠或股東看）：

1. 開 <https://app.netlify.com/drop>
2. 把 `web\index.html` 直接拖進去
3. 立刻得到 `https://xxxx.netlify.app` 網址（免費、免註冊即可先試）

> Google Drive 不能直接渲染 HTML，所以雲端上的 `06_網頁\index.html` 只能下載後本機開。
> 要公開網址請用上面的 Netlify Drop，或 Cloudflare Pages／GitHub Pages。
