# 01 品類對標分析（不抄品名、不抄配方）

版本：v1.0｜建立日：2026-10-25

## 1 目的與方法

目的：了解台灣頂級保養市場的**品類結構**，作為我方產品線規劃的輸入。

方法限制（刻意設定）：
- 只記錄**品類**（category）、**功能定位**、**劑型**、**價位帶**、**通路型態**。
- **不記錄**他人品名、不記錄他人全成分表、不記錄他人比例。
- 資料來源為公開官網品類頁與公開市場觀察，屬競爭者品類掃描（competitive category scan），
  不是配方還原（formula reverse engineering）。

## 3 對本專案的策略結論

1. **頂級線的價值不在成分稀有，在「系統一致性」**：同一系列共用香調、質地語言、包裝語言，
   消費者感受到的是整體體驗，不是單一成分濃度。這也讓我們不必去抄任何人的配方。
2. **優先做「低門檻高頻」品類打頭陣**：潔膚、前導、保濕精華、乳霜四支先做，
   建立品質信任後再上亮白、防曬、抗老（這三類法規與檢驗成本最高）。
3. **防曬與抗老是最後才做**：防曬需 SPF/PA 實測（人體或體外），A 醇需穩定性與刺激性資料，
   兩者都會拉長打樣到上市的時間。
4. **頭皮線可與既有外泌體生髮劑專案共用供應鏈與法規路徑**，是本專案與 Rokaizumi 主線的接點。
5. **禮盒是最快產生「頂級感」與高客單的品類**，但必須等單品穩定後再做，否則退換貨會失控。

## 4 我方定位（差異化）

| 面向 | 市場常見做法 | 我方做法 |
|---|---|---|
| 成分敘事 | 追逐單一明星成分濃度 | 強調「配方系統＋批次可追溯」 |
| 信任來源 | 代言人、見證 | 批次檢驗報告可查（RWA 上鏈） |
| 會員關係 | 點數、折扣 | 使用紀錄與貢獻紀錄分開記帳（STO＋） |
| 通路 | 專櫃、電商 | 七國同步，先台日消費者市場 |
| 價格 | 高價＝高濃度 | 高價＝可驗證的品質與權利 |

## 5 明確不做的三件事

1. 不使用他人品牌名、系列名、產品編號命名邏輯。
2. 不使用他人官網文案、圖片、影片、見證素材。
3. 不對外宣稱「與某品牌同款」「某品牌平替」「同配方」。
