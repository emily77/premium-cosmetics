# 06 成本分析 — 方法、資料來源與結果

> 版本：v1.0　｜　產出日期：2026-10-25　｜　狀態：估算值，非報價
> 所有 SKU 仍為 `enabled=false`，未經林總核定不得對外使用。

---

## 1. 這份文件回答什麼

林總問的是：「有辦法自動搜尋網路上原料的價格、自動評斷每一支的成本嗎？」

**答案：可以，但只能做到「估算」，不能做到「報價」。**

本專案建置了一套三層價格來源的成本引擎，能自動抓取公開原料價格、自動回退到業界參考價、自動計算 14 支 SKU 的逐支成本與毛利率，並產出可重複執行的報告。但公開網路價格與代工廠批量報價之間存在結構性落差，因此報告一律標示為估算值。

## 2. 三層價格來源架構

```
┌─────────────────────────────────────────────────────────┐
│  L3 人工覆寫  data/price_overrides.json                  │
│  代工廠／供應商正式報價　→ 優先度最高，有值就採用          │
└───────────────────────▲─────────────────────────────────┘
                        │ 無 L3 時往下找
┌───────────────────────┴─────────────────────────────────┐
│  L1 自動抓取  data/ingredient_prices.json                │
│  makingcosmetics.com 公開零售／批發價（USD/kg）           │
│  含合理性檢查：偏離 L2 參考價 6 倍以上或 0.15 倍以下 → 棄用 │
└───────────────────────▲─────────────────────────────────┘
                        │ 抓不到或偏離過大
┌───────────────────────┴─────────────────────────────────┐
│  L2 內建參考價  data/ingredient_master.json              │
│  82 項原料的業界行情中位數（USD/kg）                      │
└───────────────────────▲─────────────────────────────────┘
                        │ 連參考價都沒有
┌───────────────────────┴─────────────────────────────────┐
│  fallback  USD 25/kg 保守值（本次未觸發）                 │
└─────────────────────────────────────────────────────────┘
```

### 為什麼要三層

單靠自動抓取不夠。實測 82 項原料中，只有 46 項能在 makingcosmetics.com 找到對應商品（56%）。找不到的包括：

- **胜肽類**（Acetyl Hexapeptide-8、Copper Tripeptide-1）— 該站只賣複合胜肽液
- **防曬劑**（四種 UV 吸收劑全部無結果）— 屬藥粧成分，零售站不販售
- **特殊活性**（Tranexamic Acid、Madecassoside、Piroctone Olamine、Zinc PCA）
- **植物油脂**（山茶花油、摩洛哥堅果油、玫瑰果油、荷荷芭油、葵花油）— 該站以品類名販售，INCI 名對不上
- **基礎化學品**（NaOH、NaCl、EDTA、防腐劑單體）— 單價太低，零售站不拆售

這些全部回退到 L2 參考價，因此 248 筆原料明細中 **0 筆落入 fallback**，覆蓋率 100%。

## 3. 自動抓取的技術實作

### 3.1 目標網站

`makingcosmetics.com`（美國 MakingCosmetics，北美最大的小批量化妝品原料零售／批發商之一）。

選擇理由：
- 公開標價，不需登入
- 有完整 INCI 名稱與規格分級（10g / 50g / 300g / 1kg / 5kg / 25kg）
- 大批包裝的每公斤單價可作為批量價的**上限參考**
- 網站為 Salesforce Commerce Cloud（SFCC），有三個穩定的 JSON 端點

### 3.2 抓取流程

| 步驟 | 端點 | 取得內容 |
|---|---|---|
| 1 | `Search-UpdateGrid?q={關鍵字}` | 商品清單（pid + 名稱） |
| 2 | `Product-ShowQuickView?pid={pid}` | 規格清單（Size 變體） |
| 3 | `Product-Variation?dwvar_{pid}_Size={規格}` | 該規格價格（JSON） |

每筆原料最多 4 次請求，請求間隔 1.2 秒，全量 82 項約 7 分鐘。

### 3.3 名稱比對的坑（已修正）

第一版只用品質相似度（difflib），結果出現嚴重誤配：

| 目標 INCI | 誤配到的商品 | 後果 |
|---|---|---|
| Caprylic/Capric Triglyceride | Triglyceride | 抓到不相關的單體 |
| Tocopherol | Tocotrienols | 價格差 3.5 倍 |
| Decyl Glucoside | Polyglucose | 成分不同 |
| Ceramide NP | Ceramide Lotion | 抓到已稀釋的乳液，非粉體 |

修正方式：加入**關鍵詞覆蓋率**檢查。目標名稱的關鍵詞（長度 ≥3）至少要有 50% 出現在候選商品名稱中，且最終分數 = 0.5 × 字串相似度 + 0.5 × 覆蓋率，需 ≥ 0.55。

修正後誤配全部消失，命中數從 43 降到 46（部分原本的假命中改為正確命中，如 Tocopherol → Vitamin E Tocopherol Natural、Panthenol → Provitamin B5）。

### 3.4 抓取結果

| 項目 | 數量 |
|---|---|
| 原料總數 | 82 |
| L1 成功抓取 | 46（56.1%） |
| 無搜尋關鍵字（Aqua） | 1 |
| 搜尋無結果 | 15 |
| 名稱比對失敗 | 20 |

抓取結果存於 `data/ingredient_prices.json`，每筆含完整規格階梯（tiers），可看到 10g 零售價到 25kg 批發價的落差。例如玻尿酸鈉：

| 規格 | 價格 | 每公斤單價 |
|---|---|---|
| 1 kg | USD 653.45 | USD 653.45 |

角鯊烷（Squalane）：

| 規格 | 每公斤單價 |
|---|---|
| 最大包裝 164 kg | USD 482.75 |

## 4. 成本計算模型

### 4.1 配方比例正規化

`data/ingredients.csv` 的 248 列中，24 列為 `q.s.`（補足至 100%）。處理規則：

1. 有 `pct_min` / `pct_max` 者取中位數
2. `q.s.` 的 Aqua 吸收剩餘量
3. 其他 `q.s.`（pH 調整劑等）固定給 0.1%
4. 若無 Aqua 且總和 ≠ 100，按比例放大

驗證結果：13 支有配方的 SKU，比例總和全部 = 100.000%（RA-R11 為 99.999%，浮點誤差）。

### 4.2 配方密度

採質量分數加權的倒數法：

```
ρ_mix = 1 / Σ(w_i / ρ_i)
```

其中 `w_i` 為質量分數、`ρ_i` 為該原料密度（來自 `ingredient_master.json`）。水相配方約 1.00–1.02，油相配方約 0.86–0.90。

### 4.3 逐支成本公式

```
料體成本(TWD) = Σ(比例% × 原料單價 USD/kg) × 匯率 × 充填重量(g)/1000 ÷ (1 - 損耗率)
充填重量(g)   = 標示容量(mL) × 配方密度
出廠成本      = (料體 + 包材 + 充填 + 檢驗) × (1 + 代工廠管銷毛利)
總成本        = 出廠成本 × (1 + 品牌端物流管銷)
毛利率        = (建議售價 - 總成本) / 建議售價
```

### 4.4 參數假設

| 參數 | 值 | 依據 |
|---|---|---|
| 匯率 USD→TWD | 32.0 | 可用 `--usd-twd` 覆寫 |
| 製程損耗 | 3% | 乳化／充填的常態損耗 |
| 檢驗費分攤 | TWD 6／支 | 微生物、安定性、重金屬，按批量分攤 |
| 代工廠管銷＋毛利 | 20% | 台灣保養品代工行情 15–25% |
| 品牌端物流管銷 | 8% | 倉儲、物流、客服、退換貨 |
| 通路倍率 | 零售 = 通路進貨 × 2 | 百貨／藥粧通路抽成約 45–55% |

包材成本逐支指定（`scripts/cost_engine.py` 的 `PACKAGING_TWD`），從 TWD 24（40 mL 軟管）到 TWD 180（禮盒外盒）。充填成本逐支指定（`FILLING_TWD`），面膜與安瓶因需含浸／熔封而較高。

### 5.2 三個關鍵發現

**發現一：料體成本佔比偏低，包材才是主成本**

14 支中有 12 支的包材成本高於料體成本（RA-C01 打平、僅 RA-L07 防曬乳因 UV 吸收劑昂貴而料體較高）。極端案例如 RA-L08 淡斑安瓶：料體只佔 4.6%，包材佔 52.8%。這意味著**議價重點應該放在瓶器與印刷，不是原料**。

**發現二：建議售價倍率普遍過高**

零售價 ÷ 出廠成本：

| 倍率區間 | SKU | 判定 |
|---|---|---|
| 6–12 倍（合理） | RA-S13（8.1×）、RA-H05（11.2×） | 合理 |
| 12–20 倍 | RA-C01（15.1×）、RA-C02（16.1×）、RA-L08（19.5×） | 偏高 |
| 20 倍以上 | RA-L07（20.4×）、RA-S14（22.6×）、RA-R12（26.2×）、RA-H03（26.6×）、RA-H04（28.6×）、RA-L06（29.0×）、RA-R11（31.8×）、RA-N10（32.4×）、RA-N09（36.2×） | 顯著偏高 |

精品保養品的零售／出廠倍率常見 6–12 倍。超過 20 倍代表**必須有極強的品牌力與行銷預算支撐**，否則通路會要求更高折讓、或消費者直接轉向競品。

建議 P0 四支（RA-C01、RA-C02、RA-H03、RA-H04）先落在 6–8 倍區間試水溫：

| SKU | 現提議價 | 建議區間（6–8 倍） |
|---|---:|---|
| RA-C01 | 1,280 | 509 – 679 |
| RA-C02 | 1,680 | 628 – 837 |
| RA-H03 | 2,280 | 514 – 685 |
| RA-H04 | 2,880 | 605 – 807 |

**發現三：敏感度低，成本不是定價瓶頸**

料體價格 ±30% 對總成本的影響：

| SKU | 基準 | -30% | +30% | 變動幅度 |
|---|---:|---:|---:|---:|
| RA-L07（防曬） | 100 | 85 | 115 | ±15% |
| RA-N10（A醇晚霜） | 129 | 115 | 144 | ±12% |
| RA-S13（洗髮精） | 130 | 117 | 144 | ±11% |
| RA-H03（玻尿酸精華） | 92 | 86 | 98 | ±7% |
| RA-L08（安瓶） | 182 | 179 | 185 | ±2% |

即使原料漲 30%，總成本最多增加 15%。**成本控制的槓桿在包材與批量，不在原料議價。**

## 6. 這套系統的限制（必讀）

### 6.1 L1 抓取價是零售價，不是代工廠價

makingcosmetics.com 是**零售／小批量**通路。以玻尿酸鈉為例，該站 1 kg 賣 USD 653，而代工廠批量採購（25 kg 以上）通常落在 USD 250–400/kg。**落差 1.6–2.6 倍。**

因此 L1 價格只用於：
- 交叉驗證 L2 參考價是否離譜
- 判斷某原料是否為高價成分（影響配方設計）
- 提供代工廠議價的「上限錨點」

**不用於定價決策。**

### 6.2 L2 參考價誤差可達 ±40%

`ingredient_master.json` 的 `ref_price_usd_per_kg` 是業界行情中位數，來源為公開市場資訊與同類專案經驗值。同一原料因純度、粒徑、載體、供應商不同，價差可達數倍。例如維生素 C 衍生物（3-O-Ethyl Ascorbic Acid）從 USD 150 到 USD 500/kg 都有人報。

### 6.3 未計入的成本項目

- 國際運費與進口關稅（原料多為進口）
- 報關與倉儲
- 批量折扣（量大可降 20–40%）
- 匯率避險成本
- 代工廠開模費／打樣費（一次性）
- 法規登錄費（台灣 PIF、產品登錄；日本、韓國、東南亞各國另有要求）
- 商標註冊費
- 品牌行銷費、代言費、KOL 合作費
- 通路促銷折讓、退換貨損失
- 產品責任險

### 6.4 包材成本為概估

實際包材價格取決於：
- 瓶器是否為公版（公版便宜、私模需開模費）
- 印刷方式（網印／燙金／UV／雷射）
- 訂購量（MOQ 5,000 與 30,000 的單價差 2–3 倍）
- 是否含泵頭、滴管、內塞等配件

本報告的包材數字是「公版 + 基本印刷 + 中等批量」的概估，誤差 ±30%。

## 7. 如何把估算變成報價

### 步驟一：把 RFQ 寄給代工廠

`docs/04_代工廠估價需求單_RFQ.md` 已備妥 56 項估價項目。**需林總核定後才可寄出**（P-104）。

### 步驟二：把回覆填入 L3 覆寫層

編輯 `data/price_overrides.json`：

```json
{
  "overrides": {
    "Squalane": {
      "usd_per_kg": 28.5,
      "source": "安成生化 2026-11 報價",
      "moq_kg": 25
    },
    "Sodium Hyaluronate": {
      "usd_per_kg": 320.0,
      "source": "安成生化 2026-11 報價",
      "moq_kg": 5
    }
  }
}
```

### 步驟三：重跑引擎

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_cost_analysis.ps1 -SkipFetch
```

L3 有值的原料會自動採用代工廠報價，其餘維持 L1／L2。報告會標示每筆的價格層級，可清楚看出哪些已是實價、哪些還是估算。

### 步驟四：更新包材實價

把包材報價填入 `scripts/cost_engine.py` 的 `PACKAGING_TWD` 字典，重跑即可。

## 10. 結論

**「自動搜尋原料價格、自動評斷每支成本」技術上可行，且已建置完成並可重複執行。**

但必須清楚理解它的定位：

- 它給的是**成本結構的形狀**，不是**成本的金額**
- 它讓你知道**包材比原料重要**、**定價倍率過高**、**原料漲價影響有限**
- 它不能取代代工廠報價

真正的成本確定，發生在代工廠回覆 RFQ 之後。在那之前，這份報告的價值在於：**讓你在跟代工廠談判時，知道每一項的合理區間在哪裡，不會被當外行。**
