版本：v1.0｜建立日：2026-10-25｜狀態：**提案，待林總核定（P-101）**

## 1 品牌架構

| 層級 | 內容 | 說明 |
|---|---|---|
| 品牌（英） | **ROKAIZUMI ATELIER** | 與發行人 Rokaizumi 合同會社一致，ATELIER 表達工房級製作 |
| 品牌（中） | **露海澄研** | 「露」保濕、「海」來源、「澄」透明可追溯、「研」研究導向 |
| 品牌主張 | 可追溯的頂級保養 | 每一批次都有檢驗報告與鏈上憑證（RWA） |
| 命名規則 | `RA-{系列碼}{序號} {中文品名}` | 例：`RA-H03 潤澤玻尿酸精華` |

## 4 開發優先序與理由

| 優先 | SKU | 理由 |
|---|---|---|
| **P0（第一批打樣）** | RA-C01、RA-C02、RA-H03、RA-H04 | 法規門檻低、開發週期短、可組合成基礎四件組，最快建立品質信任 |
| P1（第二批） | RA-H05、RA-L06、RA-N09、RA-R11、RA-S13、RA-S14 | 需較多穩定性與相容性測試，但無需人體功效試驗 |
| P2（第三批） | RA-L07、RA-L08、RA-N10、RA-R12 | 防曬需 SPF/PA 實測；A 醇需刺激性與穩定性資料；禮盒需包裝開模 |

## 5 共用平台設計（降低成本關鍵）

| 防腐系統 | 兩套：A 套（一般線）、B 套（敏弱／眼周／頭皮） | 全部 |
| 乳化系統 | 兩套：E1（清爽 O/W）、E2（高油相 O/W） | C01、H04、L07、N09、N10 |
| 增稠系統 | 三套：水相凝露、乳霜、透明凝露 | 全部 |
| 包材 | 三種瓶型＋兩種軟管＋一種安瓶，共用瓶蓋與外盒結構 | 全部 |
| 外盒 | 同一結構，只換印刷與色號 | 全部 |

## 6 法規與宣稱限制（先寫清楚，避免後面改文案）

| 項目 | 限制 |
|---|---|
| 全成分標示 | 依化粧品衛生安全管理法，需以 INCI 中文或英文全成分標示，含量 1% 以上者依序排列 |
| 產品登錄 | 上市前需完成化粧品產品登錄，取得登錄編號 |
| PIF | 需建立產品資訊檔案，含配方、檢驗、安定性、不良反應紀錄 |
| 防曬係數 | SPF／PA 需依公告方法實測，不得自行標示 |
| 抗老／除皺宣稱 | 不得涉及醫療效能；「拉提」「除皺」等字眼需法遵審核 |
| 生髮／育髮宣稱 | 頭皮線不得宣稱生髮、治療落髮；僅能作頭皮清潔與養護 |
| 敏感肌宣稱 | 需有對應測試或文獻支持，不得無依據標示 |
| 有機／天然宣稱 | 需有驗證單位證明，不得自行標示 |
